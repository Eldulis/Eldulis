# Electrical Engineering Calculator

## Project Overview

This project is a beginner-level Python application designed to perform basic electrical engineering calculations.

It connects programming concepts with topics studied in Electrical and Electronics Engineering.

## Objectives

* Apply programming to solve electrical engineering problems.
* Calculate voltage, current, and resistance using Ohm's law.
* Calculate electrical power.
* Determine equivalent resistance in series and parallel circuits.
* Practise problem-solving, testing, and technical documentation.

## Planned Features

1. Ohm's law calculator.
2. Electrical power calculator.
3. Series resistance calculator.
4. Parallel resistance calculator.
5. Input validation and error handling.

## Technologies

* Python
* Git and GitHub

## Project Status

Planning and development.

## Learning Outcomes

This project will help develop programming, mathematical problem-solving, and technical documentation skills relevant to electrical engineering.
